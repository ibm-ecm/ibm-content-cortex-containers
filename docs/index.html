Connect via Remote MCP

IBM Content Cortex exposes its AI capabilities as a remote MCP server, letting any MCP-compatible client connect directly to your ECM repository — no local integration required.

MCP Client

Claude Desktop & IDE

Connect Anthropic Claude directly to your Content Cortex deployment. Browse repositories, search documents, trigger workflows, and perform redaction — all through natural language in Claude's chat interface.

Quick connect (claude_desktop_config.json)

{
  "mcpServers": {
    "ccx-core-mcp": {
      "url": "https://<core-mcp-host>.containers.appdomain.cloud/mcp",
      "disabled": false
    }
  }
}

🔐 Authentication is handled via OAuth 2.0 — Claude will prompt for authorization on first connect. No API keys or headers required in the config.

  • Document search & retrieval
  • Workflow creation & management
  • Redaction & LegalHold operations
  • AI-powered document summarisation
MCP Client

IBM Bob IDE

IBM Bob's native MCP support lets developers query, update, and manage enterprise content without leaving their IDE. Pair Bob's agentic skills with Content Cortex tools for end-to-end ECM automation inside your coding workflow.

Add to Bob MCP config

{
  "mcpServers": {
    "ccx-core-mcp": {
      "url": "https://<core-mcp-host>.containers.appdomain.cloud/mcp",
      "disabled": false
    }
  }
}

🔐 Authentication is handled via OAuth 2.0 — Bob will complete the authorization flow automatically on first connect. No API keys or headers required in the config.

  • In-IDE document browsing & search
  • Agentic workflow automation
  • Code-aware content operations
  • Enterprise security & SSO pass-through

Any MCP-compatible client (VS Code Copilot, Cursor, Continue.dev, and more) can connect using the same /mcp endpoint with OAuth 2.0. See the MCP integration guide for OAuth scopes, client registration, and tool definitions.

Quick Start

1

Setup Environment

git clone https://github.com/ibm-ecm/ibm-content-cortex-containers.git
cd ibm-content-cortex-containers/scripts

# Create and activate virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
2

Deploy Operators

Interactive deployment of Content and AI Services operators with guided configuration.

python deploy_operator.py
3

Configure & Deploy

Gather deployment properties, generate deployment artifacts, and validate configuration.

# Gather deployment properties
python prerequisites.py gather

# Generate deployment artifacts
python prerequisites.py generate

# Validate all properties
python prerequisites.py validate

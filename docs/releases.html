IBM Content Cortex 26.1.0 GA

📅 Q3 2026 General Availability ✓ Latest Release
View on GitHub

🎉 What's New

  • Watson Enhanced Extraction Service Operator: Intelligent document understanding and workflow orchestration for enterprise content
  • Redis Operator: High-availability Redis cache layer for Content Cortex workloads
  • PostgreSQL Operator: Embedded PostgreSQL cluster management for IBM products
  • Watson Gateway Operator: Unified gateway for AI model access and routing
  • Expanded Helm chart suite: Grows from 4 to 8 charts for complete infrastructure control
  • Multi-architecture support: Extended amd64, ppc64le, and s390x coverage
